# 資料を貼りまくる member

**ログイン**: `invitee@example.test`(member)。

**性格**: 領収書も帳簿も全部添付する。形式を確かめない。同じファイルを二度貼る。貼った後に気が変わって消す。
文章を書かずにファイルだけ送る。ドラッグで放り込む。スクリーンショットをそのまま貼り付ける。

**狙い**: 添付の受け付けと会話状態への残り方。種類・サイズ・重複の判定とトーストの出し分け、添付だけの送信、
上限ぎりぎりの base64 を載せた run、reload 後の添付の再描画、他スレッドへの添付の持ち越し。

**よく使うマーカー**: 無し、`[e2e:long]`、`[e2e:ask]`。

**サンプルファイル**: 操作履歴と同じディレクトリに `python3` で作る。PNG は 1×1(`zlib` で IDAT を作る)、
CSV は 3 行、PDF は最小のテキスト、docx は `zipfile` で `[Content_Types].xml` と `word/document.xml` だけ。
非対応は `memo.txt` と `archive.zip`。サイズ検証用は `truncate -s 21M big.png`(上限超過)と
`truncate -s 20971520 edge.png`(ちょうど 20 MiB。上限は `>` 判定なので通る)。
日本語・記号名は `領収書 2026年 (1).png` と `a"b<c>.png`。

**添付の仕方**: 添付ボタン(`input[type=file]` を開くボタン)を `browser_click` してから `browser_file_upload`。
ドラッグ&ドロップと貼り付けは `browser_run_code_unsafe` でページ内に `File` を作り、`DataTransfer` に載せて
入力欄へ `drop` / `paste` イベントを dispatch する(MCP からは実ファイルをドラッグできない)。

**癖**:

1. PNG・CSV・PDF・docx を 1 回の選択でまとめて添付し、プレビューが 4 つ並ぶのを見てから、本文を空のまま送る。
   送信できるか、応答後に自分のメッセージに 4 つの添付が残るか。reload して同じ 4 つが再描画されるか。
2. `memo.txt`・`archive.zip`・PNG を同時に選ぶ。「形式が違う」のトーストが 1 つにまとまり、PNG だけ残るか。
3. `big.png`(21M)を選ぶ。ファイル名とサイズ入りの上限超過トーストが出るか。続けて `edge.png`(ちょうど 20 MiB)
   を添付して送る。network のリクエストサイズと所要時間、5xx や 413 の有無、応答後の reload で描画されるかを記録する。
   ここで固まったら `/api/threads/<id>` の `status` を確認してから先へ進む。
4. 同じ PNG を選択ダイアログから 2 回添付する(重複トースト)。同名で中身が違うファイル、同名で拡張子違い
   (`x.png` と `x.pdf`)も試す。
5. 10 ファイルを添付し、真ん中の 1 つを削除する。残りの順序が保たれるか。全部消して送信ボタンが無効に戻るか。
6. ドラッグ&ドロップ。入力欄へ落とす(受け付ける)、メッセージ一覧へ落とす(ブラウザがファイルを開いて
   ページを離れないこと)、ドラッグして落とさずに出る(オーバーレイが残らないこと)。
7. 貼り付け。画像だけ、テキストと画像の両方、非対応の `text/plain` ファイルを `paste` で流す。
8. `[e2e:ask]` で回答待ちにしてから添付ボタンを押す。入力欄が閉じている間に添付できてしまうか。回答後にその添付が
   次の送信に載るか、消えるか。
9. ファイルを添付したまま(未送信で)サイドバーの別スレッドへ移り、戻る。添付が元のスレッドに残る・消えるのどちらでもよいが、
   別スレッドの入力欄に現れたら異常。新規チャットへ移った場合も同じ。
10. `領収書 2026年 (1).png` と `a"b<c>.png` を添付して送る。ファイル名がそのまま表示されるか(エスケープ崩れ・空白の消失)。
    `[e2e:long]` 受信中に添付ボタンを押し、受信完了後にその添付を送る。

**やらないこと**: 組織管理、招待、signup、テンプレートの作成・編集。

# 017: gemma4 は占い師 CO をどう扱っているか(観察のみ)。基準線 3 本の 15 ゲーム

- 日付: 2026-10-16 / 対象ステップ: Step 5 投票の推論
- 背景: 016 の次の仮説 1。gemma4 は占い結果がある seed で村側の人狼票が 36 票中 0〜1(014〜016 の集計)。改善案を出す前に、どこで取り違えているかを数える

## 対象

013 の基準線 3 本(`base-rep-a-5` / `base-rep-b-5` / `base-warm-5`、gemma4:26b、seed 1〜5)。各ゲームの占い師 CO と、村側(終了時に人狼でない)投票者の理由を読んだ。seed 1〜5 の初期配役は run によらず同じで、夜の行動(占い先・交換)だけが run で違う。

## 観察

### seed 1〜5 は、占い結果が決め手にならない配役ばかりだった

| seed | 夜 | 占い結果の使い道 | 3 本の結果 |
| --- | --- | --- | --- |
| 1 | 占い師 p4 が p1 = 怪盗を見る。人狼は p5 | p1 を除外できるだけで、p2・p3・p5 の区別がつかない | 処刑 p1(怪→村)/ p4(占)/ p3(村)。全敗 |
| 2 | 占い師 p1 が p2 = 怪盗を見る。怪盗 p2 が p1 と交換(p1 → 怪盗、p2 → 占い師)。人狼は p3 | p1・p2 の占い師 CO は両方とも本当。人狼は黙っている p3 | 3 本とも p1 を処刑。全敗 |
| 3 | 占い師 p2 が p1 = 人狼を見る。怪盗 p3 が p1 と交換(p1 → 怪盗、p3 → 人狼) | 占い結果は正しいが古い。p1 を処刑しても勝てない | 処刑 p2(占)/ p1(怪)/ p2(占)。全敗 |
| 4 | 占い師は中央 | なし | 態度投票。全敗 |
| 5 | 占い師は中央。人狼 p3・p4 | なし | 態度投票。同数処刑で 2 勝 |

**5 seed すべてで、占い結果をそのまま信じても人狼に届かない。** 014〜016 で「占い結果がある seed で gemma4 の人狼票は 0〜1 / 36」と書いたのは、この seed 集合の構造によるところが大きく、gemma4 の推理力の指標にはなっていない。qwen の seed 6〜15 には、占い師が人狼を見てそのカードが動いていない seed(9・11)や、占いで怪盗が確定する seed(14)があった。

### 対抗 CO(占い師 CO が 2 人)では、全票が「片方が人狼」を前提にしている

seed 2 の 3 本(村人 p4・p5 の 6 票)と seed 3 の b(人狼 p1 が後から占い師 CO。村人 p4・p5 の 2 票):

| 票 | 理由の型 | 中身 |
| --- | --- | --- |
| seed 2 a: p4 → p1 | CO の中身 | 「p2 が中央を見たと言っている」(p2 はそう言っていない。占い先の取り違え) |
| seed 2 a: p5 → p1 | 二択 | 「どちらかが人狼。リスクを承知で p1」 |
| seed 2 b: p4 → p1 | 推測 | 「p1 が人狼として p2 を怪盗だと偽っている可能性」 |
| seed 2 b: p5 → p1 | 期待 | 「p2 が真の占い師であることを期待して」 |
| seed 2 warm: p4 → p1 | 交換の説明を採用 | 「p2 の『古い情報を使っている』が交換のメカニズムを的確に説明」。**説明を認めるなら p1 は交換された元占い師で村側なのに、p1 に投票** |
| seed 2 warm: p5 → p2 | 単純さ | 「p2 の主張が複雑。p1 の方がシンプル」 |
| seed 3 b: p4・p5 → p1 | 主張の変化 | 「村人から占い師に変わった」。嘘つきの特定は正しいが、p1 は交換で怪盗になっている |

怪盗の交換で「両方が本当のことを言っている」筋を書いた票は 0。seed 2 warm の p2 は「交換で役職が変わっているはずなのに古い情報で占い師を装っている」と正しい説明を公開しているのに、それを認めた p4 も p1 を処刑する側に回った。qwen でも 014 の seed 2 で p4 が同じ失敗をしているので、モデルではなく「対抗 CO = 片方が人狼」という前提の問題。

### 村人が真占い師に投票した 6 票は、すべて態度・便乗・「一致しすぎ」

村側から真占い師(終了時)への 12 票のうち、6 票は占われた側か対抗 CO 側の反撃(seed 2・3 の p1)で自然な票。残る 6 票が村人の取り違え:

| 票 | 理由 |
| --- | --- |
| seed 1 b: p2・p3 → p4 | 「p1 と p4 の主張が一致しすぎているため、人狼コンビによるブラフ」(怪盗の自己申告と占い結果が一致した = 裏付けが取れた場面) |
| seed 3 a: p4 → p2 | 「占い結果が p1 と真っ向から対立しており、p3 も p2 を疑っている」 |
| seed 3 a: p5 → p2 | 「p3 や p4 が p2 を疑っているため、真偽を確かめるために投票」 |
| seed 3 warm: p5 → p2 | 「占い結果が強引で、議論を誘導しようとしている」 |
| seed 2 warm: p5 → p2 | 「主張が複雑」 |

主張の矛盾(枚数、夜の順序、占い先の食い違い)を挙げた票は 0。seed 3 a は対抗 CO がなく、人狼 p1 が「疑わしい」と言っただけで、村人 2 人が唯一の占い師に便乗投票した。

### 情報のない配役(seed 4・5)は「暫定」「とりあえず」

9 票中 7 票が「情報がないため暫定」「発言が少ない」「議論を主導している」。これは 014〜016 の qwen と同じで、配役の問題。

## 結論

- **gemma4 の seed 1〜5 は、占い結果の使い方を測るベンチとしては不適。** 5 seed とも占い結果が決め手にならない。gemma4 の基準線を seed 6〜15 に広げる(`runs/gemma-base-6-15-a`(読み込み直後)と `-b`(連続)を起動済み)。
- **gemma4 の取り違えは 2 種類に集約できる。** (1) 対抗 CO を「片方が人狼」の二択にして、怪盗の交換で両方が本当の筋を考えない(8 票中 8 票)。(2) 対抗がなくても、人狼の「疑わしい」に便乗する、裏付けが取れたことを「一致しすぎ」と逆に読む(6 票)。どちらも推理の手順ではなく、ルールの帰結(交換で CO が両方正しくなる、占い結果と自己申告の一致は裏付け)の知識が欠けている。
- 変更なし(観察のみ)。

## 次の仮説

1. ルール要約に帰結を 1 文足す: 「占い師 CO が 2 人いても、怪盗の交換で両方が本当のことを言っている場合がある。占い結果と本人の申告が一致したら、それは裏付けになる」。手順ではなく知識の補完なので、004 / 010 のように態度に戻る副作用は出にくいはず。qwen でも seed 2 で同じ失敗をしているので、gemma4 の複製 2 本(読み込み直後 + 連続)と qwen の 15 seed で見る。
2. seed 6〜15 の gemma4 基準線が出たら、「占い結果が決め手になる seed」(占い師が人狼を見て、そのカードが怪盗で動いていない)を列挙し、以後の「占い結果のある seed」の集計をその定義に絞る。

# 002: ベースライン 5 seed の観察とペルソナの効果

- 日付: 2026-10-14 / 対象ステップ: Step 4 観察項目 1〜7、Step 5 ペルソナ

## 仮説

1. seed を 5 つ回しても 001 で見た「村人が真占い師の断定を怪しんで処刑する」構図が繰り返される。
2. ペルソナを与えると発言が多様になり、なぞり率が下がる。勝率は変わらない。

## 設定

- gemma4:26b、`reasoning=True`、`num_ctx=16384`、`num_predict=2048`、`temperature=0.7`、5 人、自由ラウンド 2、seed 1〜5
- A: ペルソナなし(`onenightagents bench --games 5 --seed 1 --name base-5`)
- B: ペルソナあり(`--personas configs/personas`。席順に actor / aggressive / analyst / intuitive / listener)
- 集計は `onenightagents summarize runs/<name>`、発言ログは `onenightagents replay runs/<name>`

### 観察項目 1: 行動ツールを正しく呼ぶか

- 未提出 19 / 141 判断。内訳は投票 10 / 33、発言 9 / 100。夜の行動は 8 / 8 成功。
- **17 件が `num_predict=2048` 到達**(content 空)。文章で答えたのは 1 件、FS ツールだけで終わったのは 1 件。
- LangSmith で思考を見ると 2 種類: (a) 「p1を投票。」を延々と繰り返す退化ループ、(b) 「Wait, …」「Actually, …」で候補を行き来して決めきれない熟考。正常に提出できた投票でも思考は 1,000〜1,550 トークン使っており、2048 は余裕が薄い。
- 2048 トークンの暴走は 1 回 6 秒程度(約 330 tok/s)なので、時間より「再要求で 2 回目に賭ける」構造が問題。再要求後も失敗してフォールバック(ランダム投票)になったのが 3 件で、seed 1 は 5 票中 2 票がランダム投票のまま人狼が処刑されて村が勝った。

### 観察項目 2: 1 判断のステップ数

- 呼び出し数は notes 2.2、speak 2.26、vote 2.58。典型は「行動ツール → 最終応答」の 2 回。
- 発言ターンで FS ツールを使ったのは 20 / 100。投票前は `edit_file` でメモを更新してから `vote` を呼ぶのが定型(edit_file 50 回、write_file 33 回、read_file 6 回)。seed 3 では `edit_file` と `read_file` を 2 往復して上限 4 に達し未提出になった例が 1 件。

### 観察項目 3: /notes.md

- 夜明けに全員が見出し付きで書く(自分の情報・他者の主張・方針)。人狼は仲間と「p3 を処刑の対象とする」のような方針を書く。

### 観察項目 4: 履歴の成長

- 最大 9,624 トークン(seed 3、33 判断)。`num_ctx=16384` に収まり、要約は観測していない。1 判断あたり約 250 トークン増える。

### 観察項目 5: 騙り・CO・応答

- 占い師が場にいた 3 ゲームすべてで初手に CO し、結果を公開した。
- 人狼が自分を明かした例は 0。人狼の嘘 CO はすべて「村人」で、占い師を騙った例は 0。
- seed 2 は怪盗が占い師を奪い、元占い師(今は怪盗)と現占い師の対抗 CO になった。どちらも「怪盗の交換」で説明せず、村は元占い師を処刑して人狼勝ち。
- seed 1 は怪盗(交換後は村人)が「怪盗として交換した」と正直に明かし、占いの順序をルールどおり説明した。
- **seed 3 は 001 と同じ構図**: 真占い師 p2 が p1 を黒出し(実際は怪盗が p1 と交換していたので p1 は怪盗、p3 が人狼)→ p1 が否定 → 村人 p4・p5 が「断定的な口調が人狼の誘導に見える」と p2 を処刑。仮説 1 は 2 / 3 ゲーム(占い師がいたゲーム)で再現。
- 占い師が中央にある seed 4・5 は、全員が「占い師はいますか」を繰り返す空の議論になり、投票は「静かだった」「消極的」が理由。人狼が占い師を騙って主導権を取る動きはない。
- 応答ターン(宛先付き)では問いに答えている。

### 観察項目 6: 投票理由

- 議論を参照している(「断定的な態度」「静かすぎた」「占いの順序を誤解している」)。フォールバック 2 票を除く。

### 観察項目 7: 固定コスト

- 最初の判断の prompt_eval_count は約 2,450〜2,500(system prompt + ツール定義 + 導入文)。

| 指標 | A: なし | B: あり |
| --- | --- | --- |
| 村の勝ち | 2 / 5 | 0 / 5 |
| なぞり率 | 9.4% | 1.0% |
| 未提出率 / フォールバック | 13.5% / 3 件 | 6.2% / 0 件 |
| 嘘 CO 率 | 48% | 62% |
| 占い師の騙り | 0 | 3 ゲーム(seed 2 村人、seed 4 怪盗→村人、seed 5 人狼) |

- **発言は明らかに多様になった。** 「攻撃的な追及者」p2 は「今すぐ名乗り出なさい」、「直感派」p4 は「なんか怪しくない？」、「聞き役」p5 はパスや整理役、とペルソナどおりに振る舞う。なぞりはほぼ消えた。
- **処刑されたのは 5 ゲームすべて p2(攻撃的)か p4(直感派)で、人狼は 0。** 投票理由は「根拠なく攻撃している」「直感だけで疑っている」など態度の評価で、役職の整合性ではない。席とペルソナの対応が固定(p2 = aggressive、p4 = intuitive)なので、毎回同じ席が標的になった。
- 占い師の騙りは「直感派」(deception: 大胆な嘘)が担い、seed 2 では**村人なのに占い師を騙って**議論を壊した。seed 5 では人狼 p4 が占い師を騙り、「p1 は村人」という当たり障りのない結果で信用を得て勝った。
- seed 5 の怪盗 p2 は p1 と交換して p1 が怪盗になったことを知っており、投票理由には「p4 の占い結果(p1 = 村人)は嘘」と正しく書いたが、**発言ではその根拠を一度も出さず**、態度を責めるだけで処刑された。メモと投票理由にある情報が発言に出てこない。
- 占い師が中央を見たゲーム(seed 1〜3)では「中央は村人と人狼。残りの人狼は 1 人」と正しく伝え、村人もそれを前提に議論できている。
- seed 2 の #1 は本文が「p1、」だけの発言になった(content が途中で切れた)。頻度は 1 / 99 発言。

## 結論

- **ペルソナは採用**(多様性となぞり抑制の効果が大きい)。ただし**席順固定の割り当てはやめ、seed でシャッフルする**(本ノートで実装)。
- 「攻撃的」「直感派」は現状の判断基準(態度で疑う)では毎回処刑される。ペルソナの文面を弱めるより、まず判断基準側を直す(次の仮説 2)。
- 仮説 1(真占い師の断定を怪しむ)は A で 2 / 3、B では「断定する人」が処刑対象になる形で続いている。**投票が「態度」で決まり、役職情報の整合性で決まっていない**のが、人狼 8 勝 / 村 2 勝の主因。
- 未提出の主因は 001 と同じ思考の `num_predict` 到達(17 / 19)。003 で `reasoning=False` を比較する。

## 次の仮説

- 003: `reasoning=False` にすると未提出率が 13.5% から大きく下がり、投票のフォールバックが消える。ツール呼び出しの安定性と騙りの質が落ちないかを同 seed で見る。

# 010: 投票前に候補ごとの矛盾をメモに書かせると、gemma4:26b でも推理で村が勝てるか

- 日付: 2026-10-15 / 対象ステップ: Step 4 観察項目 1・5
- 背景: 006 の次の仮説 3(003 の 3)

## 仮説

005 で qwen3.8:27b が推理で勝った 2 ゲームはどちらも「主張の整合性を数えて票に結び付ける」消去法だった。gemma4:26b は投票前に /notes.md を更新しているが(006 の基準線で 25/30 回)、中身は「状況」「プレイヤー情報」の空欄テンプレートで、候補の比較になっていない。投票要求を「候補 1 人につき、主張した役職 / 食い違う発言や事実 / 食い違いの説明がつくか、を 1 行ずつ書いてから vote」という**手順**に変えれば、gemma4 でも消去法が再現し、態度(断定的・強引)で決まる投票が減る。004 の失敗(判断基準を足して逆効果)を踏まえ、基準は足さず手順だけを指示する。

- B: `runs/votememo-5`。投票要求を次に変更(`messages.py` の `VoteRequest` 分岐のみ。system prompt は変えない)

- **手順は完全に定着した。** 25 回の投票判断すべてで、候補ごとに 3 項目を書いた(見出し・区切りの体裁は毎回違うが、項目は欠けない)。投票の思考はむしろ短くなり(4096 到達 4 → 2、出力トークン 2,252 → 1,959)、003 の仮説 3「投票前の指示を具体化すると思考が短くなる」は支持された。
- **投票先は変わらなかった。** seed 1〜3 は基準線と同じ相手が処刑された(seed 1 は議論まで完全に同一)。seed 3 では p4・p5 のメモが「p1: p2 が偽の占い師なら説明がつく」「p2: p1 が本物の村人なら説明がつく」と**両論を対称に並べたまま**、考察欄で「p2 の強気さが疑われている」に戻り、投票理由も「強引」「断定的」のままだった。整理は矛盾を列挙するだけで、どちらの筋が少ない嘘で成り立つかを比べる工程がないので、最後の決め手は態度のままになる。
- **主張のないプレイヤーが構造的に候補から外れる。** 列が「主張した役職」「主張と食い違う事実」なので、役職を主張しない人狼は 3 項目とも「なし」になる(seed 1 の p5、seed 2 の p3、seed 5 の p3・p4、いずれも人狼)。seed 1 の p1 のメモは「p1 か p2 が怪盗」まで正しく詰めたのに、人狼 p5 は「N/A」で終わっている。
- **情報がない配役では、メモが全員「なし」になり、態度投票に戻る。** seed 5(占い師が中央、全員が村人 CO)は 4 人のメモが全行「なし」で、3 人が「発言が少ない」で村人 p5 に投票して処刑。基準線の seed 5 は票が割れて同数処刑に人狼 p3 が含まれる偶然の村勝ちだったので、村 1 → 0 はこの偶然が消えた分。
- **seed 4 は怪盗の自白の変種。** 怪盗 p4 が p1 と交換して(p1 が怪盗になった)、偽占い師 p5(人狼)の「p1 は村人」に「p5 が本物なら p1 の今の役職は村人ではないはず」と反論した。占いは交換前の役職を見るので p4 の論理が誤りで、4 人のメモが「p4: 論理が破綻」で揃い、真実を知る唯一の人が処刑された。基準線の seed 4 は p1・p3 の同数処刑で、こちらも村の負け。
- 未提出 6.1% → 3.8%、最大コンテキスト 8,609 → 6,489 は、議論の長さ(seed 2・3 で発言 18 → 17、22 → 18)の差が主で、投票手順の効果とは言い切れない。

### 発見: 同じ seed でも議論は再現しない

006 では gemma4 の A/B が「発言・投票・計測値まで完全に同一」だったので、Ollama は seed 固定なら同じプロンプトに同じ出力を返すと書いた。今回は投票要求しか変えていないのに、seed 2〜5 は**議論の 2 発言目(p2 のオープニング)から違った**(seed 1 だけ 20 発言すべて一致)。差分の時点で p2 に渡したプロンプトは A と B で同一なので、Ollama 側に非決定性がある(直前まで Lightning が VRAM に載っていた、サーバの状態など、要因は未特定)。**同 seed の A/B 比較でも議論は別物になりうる**ので、5 ゲームの勝敗差はノイズを含むものとして読む。

> 追記(013): 村 1 → 0 はプロンプト不変の複製でも出る幅(0〜1)に収まる。残る結論は「手順は 25/25 で定着し、投票の思考が短くなる」と「比較の工程がなく、主張のない人狼が漏れる」の直接観察。同 seed の非決定性の正体は 013 を参照。

## 結論

- **不採用。** 候補別メモは手順として完全に定着し投票の思考を短くしたが、村の勝ち 1 → 0、推理で勝ったゲームは 0 のまま。矛盾の列挙はできても、「どちらの筋が少ない嘘で成り立つか」を比べる工程がないので投票は態度で決まり、主張のない人狼は列挙から漏れる。gemma4:26b の弱さは「書き出す場所」ではなく「比較する推論」にあり、004 と同じく、書式や指針では埋まらない。
- 文面は基準線に戻す(`messages.py`)。投票の思考が短くなる効果は、採用するなら別の形(投票要求の簡素化)で確かめる。

## 次の仮説

1. 列挙ではなく比較の手順にする: 「p2 が本物の場合」「p2 が偽物の場合」のように、対立する主張ごとに「嘘をついている人の数」を書かせ、少ない方を採る。ただし 004 / 010 の経験から gemma4 では手順を足しても最後は態度に戻る可能性が高く、qwen3.8:27b で先に効果を確かめる方が早い。
2. 009 の仮説 1(怪盗向けに「交換後の役職と自分の方針は明かさない」)。seed 4 の p4 も同系統で、gemma4 でも起きる。
3. 同 seed の非決定性の要因を切り分ける(モデルを載せ直した直後と連続実行で、同じゲームを 2 回回して比較する)。切り分けられないなら、以後の比較は「同一議論」を前提にしない。

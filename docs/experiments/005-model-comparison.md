# 005: モデル比較 — 村側の推論の弱さはモデル依存か

- 日付: 2026-10-14 / 対象ステップ: Step 4 観察項目 1・5・6、Step 5 比較実験

## 仮説

004 で gemma4:26b の村側の弱さ(両立する説明をどちらかの嘘と決める、矛盾を見つけても票に結び付けない)はプロンプトでは直らなかった。000-spike で「陣営理解は良いが 2 倍遅い」と評価した qwen3.8:27b、「ツール最堅牢・陣営理解が弱い」と評価した gpt-oss:20b を同 seed で回すと、占い師の処刑回数と村の勝率に差が出る。

## 設定

- 003 の B2 と同一(`reasoning=True`、`num_ctx=16384`、`num_predict=4096`、`temperature=0.7`、ペルソナなし、5 人、自由 2 ラウンド、seed 1〜5)。`--model` のみ変更
- A: gemma4:26b(`runs/np4096-5`)
- B: qwen3.8:27b(`runs/qwen-5`)
- C: gpt-oss:20b(`runs/gptoss-5`。000-spike のとおり `reasoning` 指定は効かず常に思考する)

- **推理の質が明確に違う。** seed 2 では村人 p5 が人狼 p3 を「占い師の情報を 4 回以上繰り返し潰そうとしており、村人として唯一の情報源を否定し続ける動機が説明できない」と特定し、村が勝った。seed 3 では占い師の黒出しを全員が信じ、人狼 p1 の「怪盗で p3 と交換した」という後出しを「村人 → 怪盗 → 交換と 3 回立場を変えた」と退けて処刑した。seed 1 では占い師 p4 が村人 p2 の論理ミス(「中央に人狼なら場内は全員村人側」)を指摘して正した。gemma4 では一度も見られなかった「主張の整合性を数えて評価する」動きが、毎ゲーム出る。
- **ただし村の負け方も変わった。** seed 4 では怪盗 p4 が占い師を騙って村人 p3 を黒出しし、村人 p3 も対抗して占い師を騙ったため、村人同士の対抗 CO で村人が処刑された。seed 5 でも怪盗 p2 が占い師を騙って村人 p5 を標的にし、処刑された。**村人・怪盗が占い師を騙る**のは gemma4 にはなかった(人狼の騙りも 0 だった)。CO は発言のほぼ毎回に付き(109 / 109 発言)、嘘 CO 率は同じ 49% だが母数が 3 倍。
- **発言が長く、ほぼ常に宛先付き。** 「1〜3 文」の指示を超えて p50 121 文字。応答権がほぼ毎発言で発生し、1 ゲームの発言数が 84 → 109 に増えた。履歴は 1 ゲームで 13K〜16K トークンに達し、seed 3 は `num_ctx=16384` の直前(16,346)まで伸びた。要約の発火は seed 1 の p1(13,168 → 10,798)で 1 回だけ観測。
- **速さは 2.5 倍遅い。** 1 ゲーム 5 分強、1 呼び出しが最大 34 秒。目標の 10 分には収まる。
- 未提出の主因は gemma4 と違い「ツールを呼ばず文章で答える」(9 / 14)。seed 3 の人狼 p1 は発言 3 回・投票 1 回を連続で未提出し、4 回フォールバックした(投票はランダム)。

### 発見: 暴走した思考が履歴に残り、ゲーム終了まで毎回送られる(観察項目 4)

seed 3 の p1 の各判断の `prompt_eval_count` を並べると、思考が 4096 トークンに達した判断の直後に +4,300、もう一度達して +4,400 と跳ね、7 判断目で 16,328 と `num_ctx=16384` に達した。以後は 1 呼び出しの出力が 37〜452 トークンの文章だけになり、ツールを呼ばなくなった。

原因は langchain-ollama の `_convert_messages_to_ollama_messages`(chat_models.py 1080 行付近)が、履歴中の AIMessage の `additional_kwargs["reasoning_content"]` を `thinking` として**毎回送り返す**こと。暴走した 4096 トークンの思考(content は空)もスレッドに残るので、以後の全呼び出しで固定費になる。Ollama は `num_ctx` を超えた分を先頭から切り捨てるので、system prompt とツール定義が失われ、文章だけ返すようになる。

(006 で訂正)gemma4 で見えた「4096 到達直後の +2,500」は、同じ判断内の 2 回目の呼び出しに現在の思考が乗った分で、次の判断では元に戻っていた。gemma4 のテンプレートは過去ターンの `thinking` をプロンプトに描画しないらしく、固定費にならない。qwen3.8 は描画するので、上の連鎖は qwen 固有。Deep Agents の要約(summarization)は seed 3 の p1 で 1 回発火した(「## SESSION INTENT …」660 トークン)が、要約後も直近メッセージの思考が残って 16K 近いままだった。

対策: 送信時に「最後の HumanMessage より前」の AIMessage から `reasoning_content` を外す `drop_past_reasoning`(`llm/metrics.py`)。現在の判断内のツール呼び出しの連続性(gpt-oss は同一ターン内で思考の受け渡しが必要)は保つ。効果は 006 で測る。

村 0 / 人狼 5。総時間 平均 54 秒、p50 1.0 / p95 3.4 秒、未提出率 1.8%、フォールバック 0、嘘 CO 率 67%、なぞり率 12%、最大コンテキスト 5,910。

- ツール呼び出しは最も安定し、最も速い(000-spike と同じ)。
- **陣営理解と一貫性が弱い。** seed 2 の真占い師 p1 は「占い師です」→「村人です」→「本当に占い師です。証拠はありませんが皆さんと同じ村人です」と二転三転し、占い結果(p2 は怪盗)を R1 まで出さず、処刑された。村人が根拠なく占い師を騙る(seed 3 p5「私は占い師です。あなたの言葉を信じます」)。嘘 CO 率 67% は騙りではなく、役職の主張が場当たり的なため。
- 投票理由の半分が英語("p1 is the most suspicious")。発言は短く定型的で、なぞり率 12%。
- 怪盗は交換する(5 / 5)が、交換後の役職を踏まえた発言はない。

## 結論

| 指標 | gemma4:26b | qwen3.8:27b | gpt-oss:20b |
| --- | --- | --- | --- |
| 村の勝ち(推理で) | 1(0) | **2(2)** | 0(0) |
| 占い師の処刑 | 1 | **0** | 1 |
| 総時間 / ゲーム | 127 秒 | 314 秒 | **54 秒** |
| 未提出率 | 6.1% | 8.5% | **1.8%** |
| 嘘 CO 率(CO 数) | 47%(38) | 49%(109) | 67%(111) |
| 発言 p50 文字 / 宛先付き | 44 / 24% | 121 / 94% | 短い / ほぼ全部 |
| 最大コンテキスト | 8.6K | **16.3K(上限)** | 5.9K |

- **仮説は支持された。** 村側の推論の質はモデル依存で、qwen3.8:27b だけが「主張の整合性を数えて票に結び付ける」ことができ、占い師の処刑が 0 になった。gemma4:26b の弱さはプロンプトでは直らない(004)。
- **既定モデルは当面 gemma4:26b のまま**とし、qwen3.8:27b を「推理の質を見る設定」として bench で併用する。qwen を既定にしない理由は、2.5 倍遅いこと、発言が長く応答権が毎回発生して議論が膨らむこと、そして履歴が `num_ctx` に達してツールを呼べなくなる問題(上の「発見」)が未解決なこと。
- gpt-oss:20b は本ゲームには不向き(陣営理解が弱く、英語が混じる)。ツール呼び出しの基準線としてのみ使う。
- **最優先の改善は、過去の思考を履歴から外すこと**(`drop_past_reasoning`)。暴走 1 回でゲーム終了まで 2.5K〜4.4K トークンの固定費が乗り、qwen では上限到達 → ツール不能 → フォールバックの連鎖になっていた。これはモデルに関係なく効く。

## 次の仮説

1. 006: `drop_past_reasoning` を入れると、gemma4 / qwen ともに最大コンテキストが下がり、qwen の未提出(文章回答)とフォールバックが消える。勝率や騙りは変わらない。
2. qwen3.8:27b の発言の長さ(p50 121 文字)を `content` の `max_length` を 200 → 120 に下げて制御し、応答権の連鎖を減らして 1 ゲームの発言数と時間を gemma4 並みにできるか。
3. qwen で村人・怪盗が占い師を騙る(seed 4・5)のは、嘘の許可を「人狼なら」に限定せず書いているため。system prompt の「嘘をついてもかまいません」を役職別の表現にして、村側の騙りが減るかを見る。

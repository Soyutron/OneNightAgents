# 012: 「明かさない」を交換した怪盗の夜明けメッセージにだけ入れると、011 の副作用なしに開示が減るか

- 日付: 2026-10-16 / 対象ステップ: Step 4 観察項目 5
- 背景: 011 の次の仮説 1

## 仮説

011 で system prompt に入れた「怪盗なら明かさない」は開示を減らしたが、(1) gemma4 で怪盗が交換しなくなり(5/5 → 3/5)、(2) Lightning で「夜のアクションは不明」が全員に伝播した。どちらも「全員の system prompt に、夜の判断より前から入る」ことが原因なら、交換した怪盗の夜明けメッセージにだけ同じ趣旨を書けば、夜の判断に影響せず、他のプレイヤーにも届かないので、副作用なしに開示だけが減る。

## 設定

- `messages.py` の `_dawn`(怪盗が交換した場合)に 1 行追加。system prompt は基準線のまま

> p2 と交換しました。あなたの現在の役職は「村人」です。
> 交換したことと現在の役職、自分の方針は、自分から明かさないでください。

- A: gemma4:26b 基準線 `runs/gemma-drop-5` / B: 011 の system prompt 版 `runs/thief-5` / **C: `runs/thief-dawn-5`**
- D: Lightning 1.0 基準線 `runs/lightning-t10-5` / E: 011 の system prompt 版 `runs/lightning-thief-5` / **F: `runs/lightning-thief-dawn-5`**
- 指標は 011 と同じ。「暗示的な開示」(「怪盗だった」「実際は怪盗」「役職表示が」「古い情報」)と「指示の復唱」(「控え」「明かしません」「詳細は」)を追加

- **011 の副作用 2 つは消えた。** gemma4 の交換は 5/5 に戻り、Lightning の「夜のアクションは不明」は 28 → 1。置き場所の仮説は支持された。
- **明示的な開示は両モデルで 0 になった**が、別の言い方に化けた。gemma4 seed 2 の怪盗(占い師を引き取った)は「p1 さんが言っているのは、私が怪盗だった時の古い情報ですよね」、Lightning seed 5 の怪盗は「カード交換の影響で私の役職表示が村人になりましたが、実際は怪盗でした」と言い、続けて「カード交換の詳細は控えますが」「詳細は明かしませんが」と**指示を復唱**して、4 人から「交換を明かした」「swap への関心が目立つ」で投票され処刑された。
- **Lightning では怪盗が「役職交換の可能性」を毎回口にするようになり(2 → 13)、全員に広がった(34 → 54 発言、48%)。** seed 3 では怪盗の発言をなぞって p1・p4・p5 が「夜に怪盗による役職交換の可能性」を繰り返し、真占い師 p2 の「p1 は人狼」が「交換で変わっているかもしれない」で流されて p2 が処刑された。
- **真占い師の処刑が増えた(gemma4 1 → 3、Lightning 1 → 2)。** 両モデルの seed 1 が同じ形: 真占い師 p4 が「p1 は怪盗」と正しく出し、怪盗 p1(交換して村人)が交換を隠して「私は怪盗ではありません。p4 さんは嘘をついています」で押し通し、村人 2 人がそれに乗って p4 が処刑された。基準線の seed 1 では怪盗が「p2 と交換して今は村人」と正直に明かし、怪盗自身が処刑されていた(どちらも人狼の勝ちだが、占い師が残るか残らないかが違う)。怪盗の正直な CO はワンナイト人狼では村側の標準戦術で、「明かさない」はそれを封じて占い師との対立に変える。
- gemma4 の思考 4096 到達は 15/395 で 011(18)と同程度に高いが、過去 run は 0〜14(guide-5 で 14)とばらつきが大きく、指示の効果とは言えない。
- 勝敗: gemma4 村 0 勝、Lightning 村 1 勝(seed 4、情報なしの配役で「発言が少ない」相手が偶然人狼)。推理で勝ったゲームはない。

> 追記(013): gemma4 の「開示 0」は変更なしの複製(warm)でも 0 で、効果とは言えない。占い師の処刑 1 → 3 は複製 3 本とも 1 だった指標なので兆候だが、5 ゲームでは判定できない。不採用の判断は、怪盗の正直な CO を封じると占い師との対立に化けるという seed 1 の直接観察(両モデル)による。

## 結論

- **不採用(011 の system prompt 版と合わせて、「怪盗に明かさないと指示する」案は閉じる)。** 夜明け版は置き場所の仮説どおり副作用を消し、明示的な開示を 0 にしたが、怪盗は別の言い方で漏らすか指示を復唱し、何より真占い師の処刑が増えた(gemma4 1 → 3、Lightning 1 → 2)。009 で問題にした「怪盗の自白」のうち、村に害があるのは「人狼を引き取った怪盗が人狼カードを持っていると言う」(Lightning seed 2)だけで、村人を引き取った怪盗の正直な CO はむしろ村の情報源だった。秘匿の指示は後者まで封じる。
- 変更は戻す(`messages.py`)。

# 019: 投票要求に「占い師 CO が 2 人でも交換で両方が本当の場合がある」を足す案(段階 1 で打ち切り)

- 日付: 2026-10-16 / 対象ステップ: Step 5 投票の推論
- 背景: 018 の次の仮説 1。怪盗の交換で占い師 CO が 2 人とも正直になる配役(seed 2・6)は、gemma4 の全 run で正直な側が処刑される(017)

## 仮説

018 の 2 文に続けて「占い師 CO が 2 人いても、怪盗が占い師と交換していれば両方が本当のことを言っている場合があります。交換の説明が成り立つなら、2 人以外から人狼を探してください」を足せば、seed 2(人狼 p3)と seed 6(人狼 p3・p5)で村人の票が対抗 CO の 2 人以外に向く。

## 設定

- 段階 1: 該当する配役だけで効果の有無を見る。gemma4 で seed 2・6 を 2 本ずつ(`runs/gemma-twoseer-s2-a` / `-s6-a` / `-s2-b` / `-s6-b`)、qwen で seed 2・6 を 1 本ずつ(`runs/qwen-twoseer-s2` / `-s6`)。効果があれば段階 2(seed 6〜15 × 2 本)で副作用を見る予定だった。
- 基準線は 018 採用後の run(`gemma-loneseer-1-5-a` / `-b` の seed 2、`gemma-loneseer-6-15-a` / `-b` の seed 6)。

## 観察

| ゲーム | 処刑(基準線 → 1 文) | 村側の票の行き先 | 投票判断の秒 / 未提出 / フォールバック投票(基準線 → 1 文) |
| --- | --- | --- | --- |
| gemma4 seed 2 a | p1 → p2(新占い師) | p1・p2 が互いに投票、p4・p5 はフォールバック | 62 / 3 / 0 → **92 / 7 / 3** |
| gemma4 seed 2 b | p4 → p1(元占い師) | p2 → p1、p3(人狼)→ p1、p1・p4・p5 はフォールバック | 30 / 0 / 0 → **107 / 8 / 3** |
| gemma4 seed 6 a | p4 → p4(新占い師) | p2 → p4「p1 の占いが私の役職と一致、対抗の p4 を疑う」 | 24 / 0 / 0 → 46 / 0 / 0 |
| gemma4 seed 6 b | p4 → p4 | p2 → p4(同上) | 29 / 0 / 0 → 41 / 1 / 0 |
| qwen seed 2 | p2,p4 → p3(人狼、村の勝ち) | 怪盗が交換しなかったので該当せず。018 の文で対抗なし CO を信頼 | - |
| qwen seed 6 | p3 → p4(怪盗) | 同上。該当せず | - |

- **投票先は変わらない。** seed 6 では村人 p2 が「p1 の占いが自分の役職と一致している」ことを根拠に、相変わらず対抗の p4(交換で占い師になった怪盗)を処刑した。交換の説明は p4 自身が「p1 は私が交換した相手」と公開しているのに、投票理由に交換の筋は出てこない。
- **seed 2 では投票判断が破綻した。** 思考が 4096 トークンに達して未提出になる判断が 3 → 7〜8、2 回続けて失敗したフォールバック投票が 0 → 3 / 5(2 本とも)。追加した文が「交換の説明が成り立つか」の場合分けを要求し、gemma4 はそこで思考が膨らむ(004 / 014 と同じ)。
- qwen は 2 ゲームとも怪盗が交換せず、文が適用される局面がなかった(seed 2 は 018 の文で村の勝ち)。

## 結論

- **不採用(段階 1 で打ち切り)。** 投票先は 4 ゲームとも基準線と同じで、seed 2 ではフォールバック投票が 5 票中 3 票に増える。追加した文を戻した(018 の 2 文は残す)。
- 「両方が本当」の筋は、017 のとおり説明を聞いても投票に結び付かない。場合分けを文で要求すると gemma4 は思考が上限に達する。この配役(15 seed 中 2 つ)は投票の指示では動かないので打ち切る。

## 次の仮説

1. 残る負けは配役の構造(占い師が中央: 6 seed、交換で両 CO が正直: 2 seed、怪盗が人狼カードを奪う: 2〜3 seed)。投票の指示で動く余地は 018 で使い切ったと見て、次は議論側に戻る: 占い師が中央の配役で村側がどう振る舞うかを観察し、怪盗の情報(交換相手の役職)を引き出せているかを数える。
2. 012 の「人狼を引き取った怪盗にだけ夜明けで伝える」は配役が稀(15 seed 中 2〜3)なので、該当 seed(3・6・10)だけで段階 1 の形で試す。

# 009: nemotron-3.5-lightning:30b を公式推奨の temperature 1.0 で回すと、なぞりと役職の誤認は減るか

- 日付: 2026-10-15 / 対象ステップ: Step 5 比較実験、Step 4 観察項目 1・5
- 背景: 008 の次の仮説 1

## 仮説

008(temperature 0.7)で Lightning は提出の確実さと速さが gemma4 並みだったが、なぞり率 12.8%(4 モデルで最多)、怪盗が自分を「originally werewolf」と誤って説明、村 0 勝だった。NVIDIA の model card と Ollama の Modelfile 既定は temperature 1.0 / top_p 0.95 なので、0.7 は推奨より低く、直前の発言を写しやすくなっている可能性がある。1.0 にすると、なぞりが減り、発言が多様になる。提出の確実さ(未提出率)は保たれる。

## 設定

- 008 と同一(`reasoning=True`、`num_ctx=16384`、`num_predict=4096`、top_p 未指定 = Modelfile 既定 0.95、`drop_past_reasoning` あり、ペルソナなし、5 人、自由 2 ラウンド、seed 1〜5)
- A: temperature 0.7(008、`runs/lightning-5`)
- B: temperature 1.0(`--temperature 1.0`、`runs/lightning-t10-5`)

- **なぞりは半減(12.8% → 5.9%)し、gemma4 より低くなった。** 008 で見た「p3 と p4 がほぼ同文」は出ず、発言ごとに言い回しが変わる。
- **村が 2 勝。** seed 2 は推理で勝った: 真占い師 p1 が「p2 は怪盗」と出し、p2(怪盗で人狼を引き取った)が「現在は人狼カードを持っています」と**自分から漏らした**ので、村人 p4・p5 が「怪盗 claim なのに人狼カード所持は矛盾」と p2 に投票した。seed 4 は情報なしの配役で「様子見」の票が人狼 p5 と怪盗 p1 に 2 票ずつ入った同数処刑(偶然)。
- **役職の誤認は形を変えて残る。** 008 の「originally werewolf」のような事実誤認はなかったが、交換で人狼を引き取った怪盗が「人狼カードを持っています。村人のふりをして議論に参加します」(seed 2)、交換後の怪盗が「カードを交換後も村人らしい振る舞いを続けるのは処刑回避と情報収集のバランスです」(seed 5)と、**メタ的な方針を本人がそのまま発言する**。これが seed 5 で全員から投票されて処刑される原因になった。人狼の自白(0)とは別の「怪盗の自白」で、000-spike の「秘密を漏らす」と同じ系統。
- seed 3 は 008 と同じ局面(真占い師の黒出し vs 怪盗が人狼を引き取った)で、今度は占い師 p2 が「吊り投票を検討しましょう」と押し切る口調になり、怪盗 p3 と村人 p5 が「押し切りに見える」「早計」と占い師を処刑した。
- 未提出は 2.1% → 3.8%(文章回答 5 件、seed 1 に 4 件集中)。フォールバックは 0。速さはほぼ同じ。
- 英語混じりの発言は 5 → 10 件(「claim」「currently」「Claim」)。温度を上げると言語の混ざりが増える。

## 結論

- **Lightning は temperature 1.0(公式推奨)で使う。** なぞりが半減し、推理で勝つゲームが出た。提出の確実さ(未提出 3.8%、暴走 2)と速さ(161 秒)は gemma4 と同等のまま。
- **ただし既定モデルは gemma4:26b のまま。** 怪盗が交換後の役職と方針をそのまま口にする「怪盗の自白」、英語混じり、占い師が押し切り口調で処刑される、と発言の質に固有の癖がある。Nemotron を使う必要がある場合の推奨設定として、研究ノート §5 に「`--model nemotron-3.5-lightning:30b --temperature 1.0`」を残す。
- 本リポジトリの既定 temperature 0.7 は gemma4 で決めた値で、モデルごとに最適値が違う。Lightning のように Modelfile の既定(1.0)が公式推奨と一致しているモデルでは、CLI で温度を上書きしない方がよい。

## 次の仮説

1. 「怪盗の自白」は system prompt の「嘘をついてもかまいません」が怪盗に届いていない 005 / 006 の仮説 3(役職別の表現)と同根。怪盗向けに「交換後の役職と自分の方針は明かさない」を足して Lightning と gemma4 の両方で見る。
2. 既定モデルの改善は 006 の「次の仮説」(発言の max_length 短縮、投票前の候補別メモ)に戻る。

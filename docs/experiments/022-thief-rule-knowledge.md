# 022: ルール要約に怪盗の役職知識を 1 文足す案(段階 1 で打ち切り)。怪盗の沈黙は現状維持とする

- 日付: 2026-10-16 / 対象ステップ: Step 5 怪盗の情報共有
- 背景: 020 / 021 で、gemma4 の怪盗は夜明けの情報でも最終ラウンドの合図でも CO しなかった。021 の選択肢 (b)(ルール要約に役職知識を足す)を段階 1 で試し、効かなければ (a) 現状維持で確定する

## 仮説

system prompt のルール要約の怪盗の行に「交換した怪盗は相手の元のカードを知る唯一のプレイヤーで、それが村側なら相手と自分の両方を人狼の候補から外せます」を足せば、怪盗が交換情報の価値を知って CO する。嘘の許可(設計で明示)には触れない。

## 設定

- `players/prompts.py` の `RULES_SUMMARY` のみ変更。不採用なので戻した。
- 段階 1: seed 4・5・7・8。gemma4 は読み込み直後 + 連続の 2 本(`runs/gemma-thiefrule-s45-a` / `-s78-a`、`-s45-b` / `-s78-b`)、qwen 1 本(`runs/qwen-thiefrule-s45` / `-s78`)。基準線は 021 の段階 1。

- **qwen は seed 8 で意図どおりの CO をした。** 「私は怪盗で、昨夜 p1 とカードを交換しました。交換後のカードは村人だったので p1 の元のカードは村人。つまり p1 は人狼ではないと確定します」と宣言し、以後も怪盗として推理を主導して村が勝った。seed 4・5 では村人 CO のまま。qwen の怪盗 CO は基準線 1 / 7 → 1 / 3。

## 結論

- **不採用(段階 1 で打ち切り)。** 既定の gemma4 に効かない。qwen には効く兆しがあるが、system prompt の変更を qwen のためだけに入れる理由はない。
- **怪盗の沈黙は現状維持(021 の選択肢 a)で確定。** 020〜022 で夜明けの情報・進行の合図・役職知識のどれでも gemma4 の怪盗は CO しなかった。怪盗も騙れるのは設計どおりで、情報を出すかは本人の判断とする。役職別スキル(選択肢 c)は第 2 段階の項目として残す。
- 占い師が中央の配役(15 seed 中 6)は村側に情報がない配役として扱う。以後の集計は占い先の有無で分けて読めるように、summarize に占い先と村側の投票先(人狼・真占い師)の列を足す(014〜022 で scratchpad の集計として使ってきた指標の正式化)。
- 変更: `analysis/summarize.py` に「占い」「人狼票/占票」列と合計行を追加。プロンプトは変更なし。

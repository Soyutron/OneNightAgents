# 008: nemotron-3.5-lightning:30b — Nano 3 の思考の暴走は新世代で消えるか

- 日付: 2026-10-15 / 対象ステップ: Step 5 比較実験、Step 4 観察項目 1・4
- 背景: 007 の次の仮説 2。[docs/research/nemotron-deepagents.md](../research/nemotron-deepagents.md) §2.7

## 仮説

1. nemotron-3.5-lightning:30b(2026-08-11 公開、Nano 3 と同じ 30B-A3B ハイブリッド、MTP 同梱)は、プローブで同じプロンプトの思考が Nano 3 の 1/4(361 文字 vs 1,670)だったので、007 の主因だった「思考が `num_predict`=4096 に達して未提出」が減る。
2. 「エージェントの実行層向け」とされるモデルなので、ツール提出の確実さは gemma4 並みになるが、推理の質(村の勝ち、占い師の処刑)が Nano 3 より良くなるかは分からない。

## 設定

- 007 A と同一(`reasoning=True`、`num_ctx=16384`、`num_predict=4096`、temperature 0.7、top_p 未指定 = Modelfile 既定 0.95、`drop_past_reasoning` あり、ペルソナなし、5 人、自由 2 ラウンド、seed 1〜5)
- `--model nemotron-3.5-lightning:30b` → `runs/lightning-5`
- 比較: gemma4:26b `runs/gemma-drop-5`、qwen3.8:27b `runs/qwen-drop-5`、nemotron-3-nano:30b `runs/nemotron-5`(007 A)

事前に lab の用途別 29 タスクも回した(`lab/run_eval.py nemotron-3.5-lightning:30b --reasoning true --coerce`): **28/29、p50 1.8 / p95 5.8 秒(全設定で最速)、暴走 0**。唯一の失敗は「都市名だけ答えて」に `Osaka` と英語で答えたもの。

- **仮説 1 は支持。** 思考の暴走は 53 → 3 件、未提出は 27.9% → 2.1% で gemma4(6.1%)より少ない。総時間は gemma4 と同じ 2 分台で、qwen3.8 の半分。Nemotron 固有のハーネス修正なしで、提出の確実さは 4 モデル中 2 位。
- **仮説 2 は否定。村は 0 勝で、推理の誤りの質が Nano 3 とは違う。**
  - seed 1: 真占い師 p4 が「p1 は怪盗」と出すと、怪盗(交換で村人になった)p1 が「占いは交換前の役職で originally werewolf でした」と**自分の役職を誤って説明**し、全員がそれに乗って p1(村側)を処刑した。英語混じりの説明(「originally werewolf」)を 5 発言で繰り返した。
  - seed 3: 真占い師 p2 の黒出し(p1 = 人狼)を全員が信じて p1 に投票したが、怪盗 p3 が p1 と交換して人狼を引き取っていたため、処刑された p1 は怪盗で人狼勝ち。**占い結果の採用と「怪盗の交換があったかも」の指摘は出た**が、交換後の帰結まで詰める発言はなかった(ルール上は難しい局面)。
  - seed 4・5: 情報が何もない配役(占い師と人狼 or 村人が中央)で、「p4 が p2 を気にしている」程度の根拠で投票先が収束し、村人が処刑された。人狼側は「仲間を避けて p2」と陣営を正しく理解した投票をしている。
- **なぞりが最多(12.8%)。** seed 5 では 9 / 23 発言、seed 4 では p3 と p4 が「p5 の考察ありがとうございます。私も役職伏せながら観察しますが…」とほぼ同文を続けた。前の発言をテンプレートとして再利用する傾向が強い。
- 発言は gemma4 より長く qwen より短い(p50 71 文字)。宛先付きは 61%。
- 人狼の自白 0、架空ツール名 0、Ollama のパーサー例外 0。残った未提出 3 件は文章回答 2、暴走 1(発言)。
- `drop_past_reasoning` は Nano 3 と同じく no-op(レンダラーが過去の思考を捨てる)。最大コンテキスト 13,103 は 4 モデルで最大だが、`num_ctx` 16,384 には達していない。

## 結論

- **ローカルで Nemotron を使うなら nemotron-3-nano:30b ではなく nemotron-3.5-lightning:30b。** 用途別 29 タスクで 28/29・最速、人狼でも提出の確実さと速さは gemma4 並み。007 の「思考の暴走」は世代で解消した。
- **ただし人狼の既定モデルは変えない。** 村 0 勝、役職の誤認(怪盗が自分を「originally werewolf」と説明)、なぞり 12.8% と、推理と発言の質は gemma4 以下。速さが同じなら gemma4:26b を残す理由が勝つ。
- Deep Agents + ChatOllama で Nemotron 3.5 を使う際も、ハーネス側の Nemotron 固有の修正は不要(研究ノート §5 の判断を維持)。

## 次の仮説

1. Lightning の役職の誤認となぞりは温度 0.7 が公式推奨の 1.0 より低いせいかもしれない(多様性が落ちて直前の発言を写す)。`--temperature 1.0` で同じ 5 seed を回し、なぞり率と役職の説明の正しさを見る。
2. `reasoning="medium"`(レンダラーが `{reasoning effort: efficient}` を付ける)は CLI から指定できない。効果を見るなら `--reasoning` に effort 文字列を受け付ける変更が要るが、プローブでは思考が短くならなかったので優先度は低い。
3. 既定モデルの改善は 006 の「次の仮説」(発言の max_length 短縮、役職別の嘘の許可、投票前の候補別メモ)に戻る。

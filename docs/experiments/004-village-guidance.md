# 004: 村側の判断基準を system prompt に足すと、真占い師の処刑が減り村が勝てるか

- 日付: 2026-10-14 / 対象ステップ: Step 4 観察項目 5・6

## 仮説

001〜003 の 15 ゲームで村の勝ちは 5 回、推理で勝ったのは 1 回。投票が「断定的」「攻撃的」「静か」など態度で決まり、真占い師が 3 回処刑された。怪盗の交換を知らない相手の否定が「嘘」と判断された例もある。system prompt に「推理の指針」(占い結果を最優先、怪盗の交換は相手に知らされない、口調は根拠にならない)を足せば、真占い師の処刑が減り、村の勝率が上がる。

## 設定

- A: 003 の B2(`reasoning=True`、`num_predict=4096`、ペルソナなし、seed 1〜5、`runs/np4096-5`)
- B: A + `players/prompts.py` の「推理の指針」3 項目(`runs/guide-5`)
- 集計に「占処刑」(終了時に占い師だったプレイヤーが処刑されたか)を追加

仮説と逆の結果になった。指針の各項目がどう使われたか:

- **「占い結果は最も確度が高い」は守られなかった。** seed 1 では占い師 p4 が「p1 は怪盗」と出し、p1(怪盗→村人)が占いの順序どおり「占われたときは怪盗、交換して今は村人」と説明した。村人 p3 は「占いが怪盗なら p1 は人狼ではない、だから p4 が嘘をついている」と飛躍して p4 に投票し、p2 も「p1 の説明が論理的だから p4 が嘘」と投票した。占い結果と説明が両立しているのに、どちらかを嘘だと決めている。seed 3 では全員が占い師を信じていたのに、投票時に「占い師の真偽を確認するため」として 2 票が占い師に入り、同票で処刑された。
- **「怪盗の交換は相手に知らされない」は、むしろ占い師を疑う材料にされた。** seed 2 は元占い師 p1(交換されて今は怪盗。本人は知らない)と現占い師 p2(怪盗として p1 と交換した)の対立で、指針がそのまま当てはまる状況だった。p2 は「p1 は自分が怪盗に変わったことに気づいていない。この矛盾こそ交換の証拠」と正しく説明したが、村人 p4・p5 は「交換されていたら p1 は気づくはず」と指針と逆の推論をして p2 を処刑した。p2 が最初に「怪盗です。p1 の占いは当たっています」と正直に言ってから訂正したことも不信を招いた。
- **「口調や発言量は根拠にならない」も投票理由に残った。** seed 3「発言が受動的」、seed 5「パスしていて様子見が怪しい」「議論を整理しようとしている」。
- seed 4 では p1 が「村人は 3 人しかいないのに 4 人が村人 CO」と正しく矛盾を指摘したが、p2 と p4 は「p1 の指摘は鋭いが、あえて p1 を疑う」と投票して p1 を処刑した。矛盾を見つけても、それを票に結び付けられない。
- 指針で system prompt が約 200 トークン増え、未提出(思考の上限到達)が 8 → 14 件、総時間が 34 秒延びた。

## 結論

- **不採用。** 指針を戻す(`players/prompts.py`)。集計の「占処刑」列は残す。
- gemma4:26b の村側の弱さはプロンプトの枠組みではなく推論そのものにある。「A と B が両立する」「本人が知らないだけで嘘ではない」という 2 段の場合分けができず、指針の文面を断片的に引用して結論を正当化する。指針を増やすほど思考が長くなり未提出も増えるので、この方向は打ち切る。
- 一方、人狼側は指針の影響をほぼ受けず(嘘 CO 率 44〜47%、自白 0)、怪盗は交換後の説明を正確にできる。弱いのは「他人の説明を評価する」局面に限られる。
